| 항목 이름         | 저장할 자료형           | 기본값 또는 만드는 방법           | 의미 |
|                  |                        |                                  |      |
| `id`             | 정수 `int`              | `Store.new_id()`로 발급          | 지출 번호 |
| `date`           | 문자열 `str`            | 필수 입력                        | `"2026-11-17"` 형식의 지출 날짜 |
| `payer`          | 문자열 `str`            | 필수 입력                        | 돈을 낸 사람의 이름 |
| `amount`         | 정수 `int`              | 필수 입력                        | 쉼표·원 표시가 없는 원 단위 금액 |
| `members`        | 문자열 목록 `list[str]` | 필수 입력, 빈 목록 불가            | 이 지출을 나눌 사람들 |
| `category`       | 문자열 또는 `None`      | 미지정이면 `None`                 | 지출 분류 |
| `memo`           | 문자열 `str`            | 미지정이면 `""`                  | 메모 |
| `deleted`        | 참·거짓 `bool`          | 새 지출은 `False`                | 삭제 표시 |
| `weights`        | 사전 `dict` 또는 `None` | 미지정이면 `None`                | 사람별 분담 비율 |
| `category_fixed` | 참·거짓 `bool`          | 새 지출은 `False`를 기본으로 제안 | 수동 지정 분류의 고정 여부 |

**예시** 
{
    "id": 1,
    "date": "2026-11-17",
    "payer": "양정현",
    "amount": 9000,
    "members": ["양정현", "신동훈", "이은경"],
    "category": "식비",
    "memo": "회의 후 저녁",
    "deleted": False,
    "weights": None,
    "category_fixed": False
}
이 예시는 다음 뜻입니다.
양정현이 2026년 11월 17일 식비 9,000원을 냈다.
양정현·신동훈·이은경이 균등하게 부담한다.
아직 삭제되지 않았고, 분류도 고정하지 않았다.
