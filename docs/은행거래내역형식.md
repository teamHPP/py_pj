# 은행 거래내역 파일 형식 (Tarnwick 제휴 은행)

모임 통장의 거래내역을 내려받은 CSV 파일이다. `python -m moim budget import-bank <파일>` 로 가져온다.

## 파일
- 글자 인코딩: CP949(엑셀 기본 저장 형식). UTF-8 파일도 읽는다.
- 첫 줄은 열 이름이다. 열 순서는 바뀔 수 있으므로 열 이름으로 읽는다.

## 열
| 열 이름 | 내용 | 예 |
|---|---|---|
| 거래일자 | 점으로 구분한 날짜 | 2026.11.03 |
| 거래시각 | 24시간 표기 | 19:42 |
| 적요 | 출금이면 사용처, 입금이면 입금자 이름 | 회의 후 저녁 / 이서연 |
| 출금액 | 원, 쉼표 있을 수 있음, 입금이면 빈칸 | 48,000 |
| 입금액 | 원, 쉼표 있을 수 있음, 출금이면 빈칸 | 20,000 |
| 잔액 | 거래 뒤 통장 잔액 | 152,000 |

## 가져오는 방법
- 출금 줄: 총무(설정 파일의 `treasurer` 또는 `--treasurer`)가 낸 지출로 넣는다. 참여자는 그날의 회원 전원이다. 메모는 적요다.
- 입금 줄: 적요의 이름으로 회비 입금을 기록한다. 이름이 명부에 없으면 그 줄은 오류로 보고한다.
- 출금과 입금이 한 줄에 함께 있거나 둘 다 0이면 오류로 보고한다.
- 이미 들어간 거래(같은 날·같은 금액·같은 적요의 출금, 같은 날·같은 사람·같은 금액의 입금)와 파일 안에서 완전히 같은 줄은 중복으로 건너뛰고 줄 번호를 보여 준다. 같은 파일을 두 번 가져와도 두 번 들어가지 않는다.
- 오류 줄은 건너뛰고 나머지는 가져온다. 오류는 파일의 줄 번호와 함께 보여 준다.

## 예
```
거래일자,거래시각,적요,출금액,입금액,잔액
2026.11.01,09:10,이서연,,20000,20000
2026.11.03,19:42,회의 후 저녁,"48,000",,-28000
```
